Física: Leis de Newton
Questão:

Um objeto de 10kg está sendo acelerado a 5 m/s². Calcule a força resultante atuando neste objeto de acordo com a Segunda Lei de Newton.

Sua resposta:

25 N

Resposta correta:

50 N

Explicação:

De acordo com a Segunda Lei de Newton, F = m × a, onde F é a força resultante, m é a massa e a é a aceleração. Substituindo os valores:

F = 10 kg × 5 m/s² = 50 N

Você parece ter cometido um erro de cálculo multiplicando incorretamente os valores.

Matemática: Álgebra
Questão:

Resolva para x: 2x² + 5x - 7 = 0

Sua resposta:

x = 1 e x = -3.5

Resposta correta:

x = 1 e x = -7/2

Explicação:

Para resolver a equação quadrática 2x² + 5x - 7 = 0, podemos usar a fórmula quadrática:

x = [-b ± √(b² - 4ac)] / 2a, onde a=2, b=5, c=-7

Substituindo os valores: x = [-5 ± √(25 + 56)] / 4 = [-5 ± √81] / 4 = [-5 ± 9] / 4

x = (-5 + 9) / 4 = 4/4 = 1 ou x = (-5 - 9) / 4 = -14/4 = -7/2

Você acertou uma das raízes (x = 1), mas converteu incorretamente -7/2 para decimal como -3.5.
